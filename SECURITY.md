# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |

## Reporting a Vulnerability

Security is paramount for `wordpress-mcp` as it interfaces with production WordPress environments.

If you discover a security vulnerability or bypass of the **Zero-Trust Safe Mode**:

1. **Do NOT open a public issue.**
2. Please privately report the issue to **Amin Zahed** via email: `33557849+Aminzahed@users.noreply.github.com` or via GitHub Security Advisories.
3. Include detailed steps to reproduce the vulnerability.
4. We aim to acknowledge reports within 24 hours and patch critical security issues promptly.
